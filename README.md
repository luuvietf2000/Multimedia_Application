Multimedia Application (Qt Framework)

Ứng dụng đa năng phát triển bằng Qt với GUI QML và xử lý logic bằng C++, gồm:
  + Trình phát & tải nhạc trực tuyến (Zing MP3 API).
  + Tra cứu địa điểm & định tuyến (OpenStreetMap + OSRM).
  + Hiển thị thông số tốc độ & năng lượng (UART).
  + Game cờ caro với chế độ PvP và PvE (AI chọn nước đi tối ưu).
