# Multimedia_Application
Framework: Qt
Tính năng chính:
  + Lập trình GUI sử dụng QML và xử lí logic sử dụng C++
  + Trình phát & tải nhạc trực tuyến: Tích hợp API Zing MP3 để phát/tải nhạc, hỗ trợ điều khiển phát lại, hiển thị ảnh bìa, tên bài hát và ca sĩ.
  + Tra cứu địa điểm & định tuyến: Sử dụng OpenStreetMap + OSRM API để tìm kiếm địa điểm, tính toán lộ trình theo phương tiện, hiển thị bản đồ trực tiếp trong ứng dụng.
  + Hiển thị thông số tốc độ & năng lượng: Thu thập dữ liệu qua UART, hiển thị trực quan thông số tốc độ và năng lượng tiêu thụ trên giao diện.
  + Game cờ caro: Phát triển game với 2 chế độ PvP và PvE, trong đó Computer chọn nước đi tối ưu dựa trên tính toán điểm tấn công và phòng thủ.
